# ⌨️ dotfiles & tmux 주요 단축키 가이드 (Keybindings Guide)

본 문서는 dotfiles 환경(tmux, sidebar launcher, 터미널 등)에서 제공하는 주요 단축키와 마우스 조작법을 정리한 레퍼런스입니다.

---

## 📌 기본 Prefix 키

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + a`** | tmux 기본 Prefix (기존 `Ctrl + b`에서 변경됨) |

---

## 🗂️ 1. 사이드바 및 세션 관리 (Sidebar & Session Launcher)

| 단축키 | 기능 설명 | 세부 동작 |
| :--- | :--- | :--- |
| **`Ctrl + a` &rarr; `s`** | **사이드바 토글** | 좌측 고정 사이드바를 열거나 닫습니다 (크기 및 레이아웃 자동 보존). |
| **`Ctrl + a` &rarr; `P`** (`Shift+p`) | **서브페인 상/하 위치 전환** | 세션 목록과 서브페인의 상/하 배치를 즉시 스왑하고 위치를 기억합니다. |
| **`Ctrl + a` &rarr; `T`** (`Shift+t`) | **테마 피커 (Theme Picker)** | 38종의 고급 컬러 테마를 실시간 미리보기하며 선택합니다. |
| **`Ctrl + a` &rarr; `/`** | **커맨드 팔레트 (Palette)** | 전체 단축키 검색 및 즉시 실행 팝업을 엽니다. |
| **`Ctrl + a` &rarr; `h` / `?`** | **도움말 가이드 (Help Viewer)** | 전체 단축키 및 기능 설명 팝업 창을 엽니다. |

### 📋 사이드바 내부 TUI 단축키
사이드바에 포커스가 있을 때 아래 키를 직접 입력합니다:

| 키 | 기능 | 설명 |
| :--- | :--- | :--- |
| **`j` / `k`** 또는 **`↓` / `↑`** | 세션 이동 | 세션 목록 커서를 아래/위로 이동합니다. |
| **`Enter`** | 세션 전환 | 선택한 세션으로 즉시 전환합니다. |
| **`s`** (또는 `m`) | 서브페인 토글 | 사이드바 내 서브페인(터미널)을 켜거나 끕니다. |
| **`P`** | 서브페인 위치 스왑 | 서브페인 상단 ↔ 하단 배치를 맞바꾸고 기억합니다. |
| **`c`** | 새 세션 생성 | 이름을 입력받아 새 세션을 생성합니다. |
| **`r`** | 세션 이름 변경 | 현재 선택한 세션의 이름을 변경합니다. |
| **`d`** | 세션 삭제 (Archive) | 세션 상태를 안전하게 아카이브 보관 후 삭제합니다. |
| **`o`** | 히스토리/복원 화면 | 삭제된 세션 아카이브 목록을 보고 복원(`Enter`)합니다. |
| **`h` / `?`** | 도움말 팝업 | 전체 단축키 안내 팝업 창을 엽니다. |
| **`Esc` / `q`** | 사이드바 닫기 | 사이드바를 닫고 작업 영역으로 복귀합니다. |

## ✂️ 2. 작업 영역 페인 분할 (Pane Splitting)

> [!NOTE]
> 사이드바가 열려 있는 상태에서 분할해도 **사이드바 영역은 완벽하게 보호되며, 작업 영역(Work Pane)만 안전하게 분할**됩니다.

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + a` &rarr; `\|`** 또는 **`%`** | **가로 분할 (좌 / 우)** |
| **`Ctrl + a` &rarr; `_`** 또는 **`"`** | **세로 분할 (상 / 하)** |
| **`Ctrl + a` &rarr; `c`** | **새 윈도우 생성** (현재 경로 유지) |

---

## 🧭 3. 페인 포커스 이동 (Navigation - Prefix 불필요)

Prefix(`Ctrl + a`)를 누를 필요 없이 바로 입력합니다:

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Alt + ←`** (`M-Left`) | 왼쪽 페인으로 포커스 이동 |
| **`Alt + ↓`** (`M-Down`) | 아래쪽 페인으로 포커스 이동 |
| **`Alt + ↑`** (`M-Up`) | 위쪽 페인으로 포커스 이동 |
| **`Alt + →`** (`M-Right`) | 오른쪽 페인으로 포커스 이동 |
| **`Ctrl + \`** | 이전에 사용하던 페인과 토글 |

---

## 🔄 4. 페인 위치 맞바꿈 (Pane Swapping - Prefix 불필요)

Prefix 없이 현재 페인의 물리적 위치를 인접 페인과 맞바꿉니다:

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + Alt + ←`** | 왼쪽 페인과 위치 스왑 |
| **`Ctrl + Alt + ↓`** | 아래쪽 페인과 위치 스왑 (사이드바 내부: 서브페인 하단 배치 및 기억) |
| **`Ctrl + Alt + ↑`** | 위쪽 페인과 위치 스왑 (사이드바 내부: 서브페인 상단 배치 및 기억) |
| **`Ctrl + Alt + →`** | 오른쪽 페인과 위치 스왑 |

---

## 📏 5. 페인 크기 조절 (Resizing)

| 조작법 / 단축키 | 기능 설명 |
| :--- | :--- |
| **마우스 드래그** | 가로/세로 경계선을 클릭 & 드래그하여 실시간 크기 조절 (크기 자동 기억) |
| **`Ctrl + a` &rarr; 방향키 (`↑`/`↓`/`←`/`→`)** | 방향키 방향으로 1칸씩 미세 크기 조절 |
| **`Ctrl + a` &rarr; `Alt + 방향키`** | 방향키 방향으로 5칸씩 빠른 크기 조절 |

---

## 📑 6. 윈도우 탭 이동 (Window Tabs)

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + a` &rarr; `Tab`** | 다음 윈도우 탭으로 이동 |
| **`Ctrl + a` &rarr; `Shift + Tab`** (`BTab`) | 이전 윈도우 탭으로 이동 |

---

## 📋 7. 복사 모드 (vi 스타일 클립보드)

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + a` &rarr; `Escape`** | vi 복사 모드 진입 (방향키 또는 `h/j/k/l`로 탐색) |
| **`v`** (복사 모드 내) | 글자 단위 블록 선택 시작 |
| **`V`** (복사 모드 내) | 줄(Line) 단위 선택 |
| **`r`** (복사 모드 내) | 사각형(Rectangle) 블록 선택 토글 |
| **`y`** (복사 모드 내) | 선택 영역을 **시스템 클립보드로 복사** 후 모드 종료 |
| **`Ctrl + a` &rarr; `p`** | 클립보드 내용 붙여넣기 |

---

## 🖱️ 8. 마우스 & 터미널 기능

| 조작 | 기능 설명 |
| :--- | :--- |
| **좌클릭** | 페인 선택 및 사이드바 세션 즉시 선택 |
| **우클릭** | 페인 분할/스왑/닫기 등을 포함한 스마트 컨텍스트 메뉴 팝업 |
| **`Ctrl + 마우스 휠`** (URxvt) | 폰트 크기 확대/축소 |
| **`Ctrl + 마우스 휠 클릭`** (URxvt) | 폰트 크기 100% 기본값으로 리셋 |
