Window-Local Presenter + Singleton Subpane Hub Model

과거의 불안정한 물리 페인 이동(move-pane) 모델을 완전히 제거하고, 논리 Coordinator 1개와 윈도우별 고정 Thin Presenter, 전역 싱글톤 Subpane Hub 구조를 채택하여 0.75ms 제자리 전환과 완벽한 레이아웃 무결성을 달성했습니다.

📦 10대 핵심 모듈 및 경계 역할 (Module Architecture)

scripts/lib/*.sh
sidebar_domain.sh Pure Domain

문자열 sanitize, 시간 경과 포맷팅, 인프라 세션 필터링, 기본 서브페인 높이/비율 계산 등 외부 I/O가 전혀 없는 순수 도메인 함수 집합.

sidebar_domain_animation.sh LUT Engine

24프레임 Look-Up Table(LUT) 파형 엔진, ANSI 그라데이션 사전 캐싱, 30 FPS 적응형 클록, CJK/Emoji 정밀 너비 측정기.

sidebar_domain_activity.sh State Machine

다중 세션 비동기 AI 활동 추적기. 프로세스 명령 정규화 및 상태 전이(active ↔ waiting ↔ idle) 관리.

sidebar_subpane_hub.sh Singleton Hub

전역 싱글톤 세션(dotfiles-subpane-hub) 수명주기, 원자적 임대(Lease), 상/하 위치 스왑 및 tmux 3.2a 테두리 보정.

sidebar_switch.sh Switch Pipeline

Native switch-client \; select-pane 원자적 파이프라인. Marker Handover 및 0.75ms 제자리 Fast-Path 보장.

sidebar_archive.sh V3 Codec

결정론적 아카이브 명명 규칙, Version 3 레이아웃 무결성 직렬화/역직렬화 및 일괄 복원(Batch Restore) 가드.

sidebar_port_tmux.sh Tmux Port

소켓 격리된 Tmux 커맨드 경계 어댑터. 옵션 읽기/쓰기, 서브페인 상/하 전환, 윈도우별 사이드바 관리.

sidebar_topology.sh Topology

윈도우 내 사이드바, 서브페인, 워크페인, 활성 페인 식별 및 클러스터 프로비저닝 단일 진실 공급원.

sidebar_coordinator.sh Pure State

선택 정렬 리듀서(selection_coordinator_align_current) 및 렌더 델타 인덱스 계산기.

🔍 아키텍처 개선 및 모듈 심화 기회 (Deepening Opportunities)

Refactoring Recommendations
Strong Recommendation

Launcher 내부 직접 tmux 호출 완전 위임 (Encapsulate direct tmux calls)

scripts/tmux-session-launcher → scripts/lib/sidebar_port_tmux.sh
Problem (현재 마찰)

tmux-session-launcher 내부에 약 30여 곳의 직접적인 tmux 호출이 남아있어, sidebar_port_tmux.sh 어댑터와의 책임 경계가 얕아(Shallow)질 위험이 있습니다.

Benefit (개선 효과)

모든 tmux I/O를 단일 Seam(sidebar_port_tmux.sh)으로 모아 Locality를 확보하고, 모의 테스트(Mock Test)의 범위를 극대화할 수 있습니다.

❌ Before: Shallow Interface & Leaking I/O
launcher -> 직접 tmux set-option
launcher -> 직접 tmux list-panes
launcher -> sidebar_port_tmux.sh (일부 혼용)
✅ After: Deep Module & Clean Boundary
launcher -> sidebar_port_*() 인터페이스만 호출
sidebar_port_tmux.sh 내부에서 모든 tmux I/O 완전 캡슐화
Worth Exploring
