## 해석

periodic refresh가 전체 snapshot을 수행하는 경우 navigation 관측 지연이 발생했으며, 선택 session의 command signature가 안정적일 때 snapshot을 생략하면 지연이 68ms로 감소했습니다. shell pane은 선택 session refresh에서 child AI probe를 유지하고 startup 전체 scan에서는 생략해 hot-path 비용을 보존했습니다. blocking read/signal timer CPU 실험은 lifecycle 회귀와 CPU 무개선으로 채택하지 않았습니다. 비선택 process probe 제한 후 CPU는 16.95/16.27%로 개선되지 않았고 periodic navigation은 71ms였습니다. v0.6.9 승격·commit/tag/push는 보류합니다.
