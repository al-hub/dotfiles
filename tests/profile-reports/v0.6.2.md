## Method

Each run created a unique tmux socket, an attached urxvt client, and a temporary history directory. It executed the launcher from the checked-out repository, never the installed copy. CPU was interval CPU time from `/proc/PID/stat` (including reaped children), and RSS was peak launcher RSS sampled during the same interval. Timed operations had bounded completion checks; all three functional runs passed.

The three runs were collected as independent invocations of `tests/profile-isolated-sidebar.sh` because the sandbox terminated the multi-run wrapper before completion. Geometry, metrics, and invariants were unchanged.
